# Sales Dashboard (Excel/Google Sheets)

## Описание проекта
Интерактивный дашборд для мониторинга ключевых показателей продаж. Проект демонстрирует навыки работы с Excel/Google Sheets, построения дашбордов и автоматизации расчётов.

## Задачи проекта
1. Создание автоматизированного дашборда
2. Визуализация ключевых метрик
3. Автоматические расчёты (конверсия, средний чек, ROI)
4. Интерактивные фильтры и срезы

## Инструменты
- Microsoft Excel / Google Sheets
- Диаграммы и графики
- Сводные таблицы
- Формулы и функции

## Как использовать
1. Скачайте файл `dashboard.xlsx`
2. Импортируйте данные из `data/sales_data.csv`
3. Обновите сводные таблицы
4. Используйте фильтры для анализа

## Ключевые метрики дашборда
- **Общая выручка** — сумма всех продаж
- **Средний чек** — средняя сумма заказа
- **Конверсия** — доля покупок от просмотров
- **Топ товары** — лучшие по продажам
- **Динамика по месяцам** — тренд продаж

## Результаты
- Автоматический дашборд обновляется при загрузке новых данных
- Визуализация ключевых метрик в одном месте
- Быстрый анализ эффективности продаж
